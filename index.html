ยังไม่ได้เชื่อม Google Drive
ข้อมูลในเครื่องยังใช้งานได้ตามปกติ
Online
🔒 แอปขอสิทธิ์ drive.file เท่านั้น เพื่อจัดการเฉพาะไฟล์ที่ ERP Consultant Hub สร้างหรือใช้งาน ไม่ได้ขอสิทธิ์อ่าน Google Drive ทั้งหมด

ตั้งค่าครั้งแรก

1) เปิด Google Cloud Console → สร้าง Project → เปิดใช้งาน Google Drive API

2) สร้าง OAuth Client ประเภท Web application แล้วใส่ URL ที่คุณ Host แอปไว้ใน Authorized JavaScript origins

3) นำ Client ID มาวางด้านบน แล้วกด “เชื่อม Google Drive”

Origin ปัจจุบัน:

การเชื่อม Google ต้องเปิดแอปผ่าน HTTPS หรือ localhost การเปิดจาก file:// ยังใช้ Local Mode ได้ แต่ Google OAuth จะไม่ทำงาน
